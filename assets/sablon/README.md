# Axion şablon dosyaları (Faz 5 — Tasarım Stüdyosu)

Canva şablonunun yerine geçecek dosyalar buraya konur. GitHub'da bu klasörü açıp
**Add file → Upload files** ile sürükleyip bırakabilirsin (dosya başına en fazla 25 MB).

| Dosya adı | Ne | Not |
|---|---|---|
| `arka_plan_1.png` … `arka_plan_8.png` | 8 arka plan, 1080×1920 (PNG veya JPG) | Numara = kullanım sırası. Her gün (02:00'de) bir sonrakine geçilir; aynı gün tüm haberler aynı arka planı kullanır. |
| `logo_kutusu.png` | Axion Haber logo kutusu, şeffaf zeminli PNG | 16. sn'de alttan yükselip geri inen kutu. |
| `ornek_canva.mp4` | Canva'dan çıkmış bitmiş örnek video | Animasyonları (merge, old tv, slow baseline) buna bakarak eşleştireceğim. |
| `slogan_1.png`, `slogan_2.png` (isteğe bağlı) | "TARAFSIZ HABERCİLİĞİN ADRESİ", "BEĞEN, PAYLAŞ, TAKİP ET" görselleri | Yoksa yazıyla üretilir. |
| `fontlar/` (isteğe bağlı) | Başlık yazı tipi (.ttf/.otf) | Yalnızca lisansı uygunsa. |

Dosya adları farklı olursa sorun değil; yüklediğini söylemen yeterli, adları ben düzeltirim.
